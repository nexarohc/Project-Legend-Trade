# Unpinned dependencies, for running on whatever Python you happen to have.
#
# requirements-server.txt pins exact versions, which is right for a deployment
# and wrong for a laptop: a pin from last year has no wheel for this year's
# Python, so pip falls back to building from source and the install dies asking
# for a C++ toolchain. This file exists so `pip install -r` resolves to whatever
# currently has wheels for your interpreter.
#
# Verified: the full test suite (705 passed, 10 skipped) runs green against the
# latest resolution of this file — fastapi 0.141, pydantic 2.13, sqlalchemy
# 2.0.51, starlette 1.5. The code uses stable APIs, so newer is not a gamble.
#
# Plain `uvicorn`, deliberately, not `uvicorn[standard]`. The extras pull in
# httptools, uvloop and watchfiles — compiled packages, two of them Rust — which
# reintroduces exactly the build failure this file exists to avoid. They buy
# throughput that matters under load and nothing at all on a laptop, so they
# live in the pinned server file instead. Verified: with this list, every
# resolved dependency installs from a pure-Python wheel, and the API starts and
# answers.
fastapi
uvicorn
pydantic
pydantic-settings
sqlalchemy
python-multipart
httpx
websockets

# EmailStr in the auth router needs this. Without it, importing the users
# router raises at collection time and every API test errors out — a failure
# that reads as a broken test suite rather than a missing package.
email-validator
