# Docs

Read in this order when picking the project back up:

- `PROJECT_STATE.md` — **start here.** The authoritative handoff document:
  what is built, every decision and why, what is deliberately absent, what
  comes next.
- `TRADING_TERMINAL.md` — how the platform works. Market coverage, the
  analysis pipeline, backtester, execution, and the full API reference.
- `../PROJECT_SPEC.md` — architecture, tech stack, folder structure, and the
  design rules the codebase is held to.
- `DEVELOPMENT_WORKFLOW.md` — the one-feature-at-a-time build process.
- `RUN_ON_WINDOWS.md` — step-by-step local setup for a non-developer.
